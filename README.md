# 🧮 Simple Calculator 

HTML, CSS ve JavaScript kullanılarak geliştirilmiş **basit ama işlevsel bir hesap makinesi** projesi.
Temel matematik işlemlerini hızlı ve kullanıcı dostu bir arayüzle yapmayı sağlar.

---

## 🚀 Özellikler

* ➕ Toplama, çıkarma, çarpma, bölme işlemleri
* 🔢 Ondalıklı sayılarla işlem yapabilme
* 🧠 Gerçek zamanlı hesaplama mantığı
* 🎯 Temiz ve sade UI tasarımı
* 💻 Responsive yapı (mobil uyumlu)
* ⚡ Hızlı ve hafif çalışma

---

## 🕹️ Nasıl Kullanılır?

* Sayıları gir
* Operatörü seç (+, −, ×, ÷)
* "=" ile sonucu gör
* "C" ile ekranı temizle 🧹

---

## ⚙️ Kullanılan Teknolojiler

* HTML5
* CSS3
* Vanilla JavaScript

---

## 🎯 Amaç

Bu proje:

* JavaScript mantığını güçlendirmek
* DOM manipulation öğrenmek
* Basit UI etkileşimlerini geliştirmek

için hazırlanmıştır.
